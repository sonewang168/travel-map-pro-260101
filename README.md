# 🌍 旅行足跡地圖 Pro

## ✨ 功能
- 📸 上傳照片，自動解析 GPS 座標
- 🗺️ 在地圖上顯示足跡
- 📷 上傳到 Google 相簿（支援繼續上傳到同一相簿）
- 📄 建立圖文並茂 Google Doc

## ⚙️ 設定
1. **Google Client ID** - Google OAuth
2. **Google API Key** - Google API
3. **ImgBB API Key** - 圖片上傳（建立文件需要）

## 🚀 使用
1. 上傳照片到 App
2. 登入 Google
3. 點「上傳相簿」（第一次會建立新相簿，之後可選擇繼續上傳）
4. 點「建立文件」製作圖文並茂記錄
